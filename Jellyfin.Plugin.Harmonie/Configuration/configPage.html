Setup

Connection

Base URL of the harmonie service. No trailing slash. Example: http://harmonie:8842.
Sent as X-API-Key. Leave empty if harmonie was started without authentication.

Path mappings

Optional. Use these only when harmonie and Jellyfin see your music library at different filesystem paths. The plugin uses them as a fallback when a track can't be matched by tags. Format: /harmonie/path => /jellyfin/path.
